# Participant task

Using only the supplied canonical scenario and the tools allowed by the assigned
arm, submit:

1. the project readiness verdict;
2. current-context satisfaction;
3. blocker and warning IDs;
4. compatible and preferred provider identities;
5. the shortest trustworthy recommendation to reach GREEN.

Do not install or remove runtimes, edit PATH, change aliases, or mutate the host.
The task is complete when the submission contains all five items.

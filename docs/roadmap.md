# Roadmap

ARX 0.3 establishes the Python project-intelligence vertical slice. Near-term extensions include:

- pip-to-interpreter mismatch detection and richer PowerShell alias/function resolution evidence;
- cross-source range intersection beyond exact `.python-version` selection conflicts;
- uv project-environment and virtual-environment discovery scoped to the selected project;
- Python package/environment satisfaction after runtime selection;
- cautious context-keyed provider observation caching;
- Project DNA adapters for Node, CMake, Gradle, .NET, Cargo, Go, Docker, and CI workflows;
- richer desktop explanation traversal and schema instance validation in CI;
- robust PE imports/resources and exact .NET targets, MSI tables, and APK manifests.

Machine-remediation execution, global PATH mutation, runtime removal/upgrades, security changes, graph databases, distributed services, and runtime plugin frameworks remain outside ARX 0.3. Predictive analysis stays separate from normal static scanning.

# ARX 2.0.0 - Project-Aware Semantic Compatibility Intelligence

ARX 2.0.0 is the first public major release of the project-aware semantic compatibility engine. It preserves the existing Windows machine/software inspection workflows while promoting the completed Python project-readiness domain across the CLI, desktop application, Evidence Inspector, schemas, and AI-facing export.

## Implemented capabilities

- bounded, static Python project inspection for `pyproject.toml`, `.python-version`, `uv.lock`, `setup.cfg`, static `setup.py` metadata, and supported requirements files;
- typed requirement evidence and a capability-grouped requirement graph with provenance, conflicts, and explicit unknowns;
- distinct resolved, healthy-compatible, project-pinned, and ARX-preferred provider roles;
- context-scoped `python`, `python3`, and `py` resolution with PATH, relevant environment, and optional account fingerprints;
- provider existence, health, architecture, scope, and stable path-based identity;
- separate current-context satisfaction, recoverability, GREEN/YELLOW/RED severity, safe recommendations, and explanation graphs;
- consistent CLI, desktop, Evidence Inspector, Project DNA, Project Preflight, and AI Contract output backed by semantic invariant guards;
- Phase II matched-arm benchmark protocols, evidence containers, neutral comparison generation, and claim gating.

## Contract compatibility

The project-aware AI Contract schema remains `0.2`. Legacy machine/software scan workflows remain on schema `0.1`. Application version `2.0.0` is independent from both schema versions.

## Evidence and claims

Phase II benchmark infrastructure exists, but the baseline and ARX-assisted evidence containers have not recorded paired benchmark observations. ARX therefore makes no efficiency, token, energy, time-savings, or economic claims in this release.

## Current scope and limitations

Python project semantic intelligence is implemented. Other project ecosystems remain future work. The conservative Python constraint evaluator leaves unsupported forms UNKNOWN. Interpreter GREEN does not verify dependency installation, lock/site-packages synchronization, project imports, or complete application execution. The planner remains advisory and never mutates the host automatically.

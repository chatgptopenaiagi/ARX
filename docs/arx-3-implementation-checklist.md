# ARX 3 implementation checklist

This checklist normalizes the ARX 3 desktop specification as literal Points 1 through 27. It is updated after each implementation stage. A point is not marked `TESTED` merely because a neighboring feature exists.

Allowed states: `NOT STARTED`, `IN PROGRESS`, `IMPLEMENTED`, `TESTED`, `PARTIALLY IMPLEMENTED`, and `BLOCKED WITH DOCUMENTED REASON`.

## Stage log

- Baseline: repository clean; Python 3.10.8; 105 tests passed in 3.81 seconds after installing declared development extras.
- Checkpoint 1 (Points 1, 14, 15, 19, 20, 21, 25): added the normalized checklist plus tested UI-neutral formatting, clipboard, safe path action, and non-sensitive state helpers. Focused result: 10 tests passed.
- Checkpoint 2 (Points 2–15, 17–21, 25): added Windows menus, selectable searchable report panels, scrollbars, path-sensitive row menus, shortcuts, safe activation, file dialogs, feedback/cancel state, error details, tooltips, DPI/state handling, accessibility basics, and About. Focused result: 31 tests passed; compile and diff checks passed.
- Checkpoint 3 (Points 16, 20, 21, 25): added the optional professional x64 installer layer while retaining portable distribution. Focused result: 33 packaging/desktop tests passed and the PowerShell parser found no errors; Inno Setup was not installed, so no binary was produced.
- Checkpoint 4 (Points 20, 21, 25, 27): added the provider-neutral advisory context/security layer, supported OpenAI Responses API adapter, current read-only Codex CLI adapter, and safe web-search bridge. Focused result: 22 new boundary tests and 78 combined boundary/desktop/hardening tests passed.
- Point 16 environment verification: `scripts/build-desktop.ps1` produced the portable payload, Inno Setup 7.1.0 compiled the versioned installer through the supplied path and later through standard-location discovery, and an independent SHA-256 comparison matched the generated manifest. Focused result: 4 packaging tests passed. Installation, uninstallation, and upgrade were deliberately not claimed because they were not exercised.
- Checkpoint 5 (Points 20, 21, 25, 27): added contextual desktop AI/web actions, provider availability UI, per-provider consent, exact prompt preview, visible source context/trust separation, modes, background requests, cooperative cancellation, and redacted conversation export. Focused results: 60 desktop/advisory tests and 71 combined hardening/boundary tests passed; the diff and compilation checks passed.
- Checkpoint 6 (Points 20, 21, 25, 27): added custom pinned and least-privilege Windows/Linux CI, package-build verification, Python/Actions CodeQL, and workflow security tests without publishing, cloud deployment, Django, or Conda. Focused result: 27 workflow/advisory boundary tests passed and a warning-free isolated sdist/wheel build completed.
- Stage 7: manual acceptance documentation, regression principles, Point 24/26/27 reports, and final audit — next.

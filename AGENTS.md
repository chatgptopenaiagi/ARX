\# ARX Codex Development Policy


For implementation, repair, testing, documentation, CI, packaging,

and repository-maintenance tasks requested by the user:


- inspect the repository without asking

- edit repository files without asking

- run tests without asking

- install normal project development dependencies when required

- use git fetch/pull/status/diff without asking

- create branches when useful

- git add and commit completed work

- push completed work to the configured origin

- use GitHub CLI for issues, pull requests, Actions and releases when required

- fix CI failures and rerun tests

- continue through normal implementation steps without requesting repeated approval


Always preserve existing work unless intentionally replacing it.


Do not delete the GitHub repository, alter account security,

expose credentials, rotate secrets, change billing, or force-push

rewritten history unless the user explicitly requests that specific action.
